Name: Massa Wallet
Summary: Self-custodial wallet for the Massa blockchain
Description: |-
    Secure self-custodial Flutter wallet for Massa (MAS):

    * Light client over JSON-RPC v2 (Buildnet & Mainnet)
    * DApp browser for on-chain .massa sites (DeWeb) with window.massa provider
    * MRC-20 tokens, deferred calls (ASC) planner
    * Staking with roll auto-compound at cycle rollover
    * Watch-only addresses, MNS (name.massa) resolution
    * Encrypted multi-account backup (.massabak)
    * Biometric unlock, screenshot guard, background sync with income alerts
    * Homescreen balance widget
    * Experimental node mode (connect your own massa-node)

    Keys never leave the device (hardware-backed keystore).
